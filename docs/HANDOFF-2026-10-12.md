## How to ship from here

1. Commit here (unsigned, in a worktree or branch). The owner pushes this repo
   (`git -C ~/src/bandit-craft push`).
2. In bandit-nix: `tools/craft-bump` (fresh worktree on origin/main, moves the input, lists the incoming
   commits, builds the lab, commits) and the owner runs the printed `tools/ship-claude <sha>`, pushes,
   and deploys with `lab-apply`.
3. bandit-nix's own changes go through `tools/ship-claude` as before (it re-signs, checks, builds).

## Lessons from today (each cost time once)

- Build the whole lab before handing over, not just checks: a `;` in an agent goal broke evaluation
  (`mcagents: the goal of bot3 must not contain ';'`) while every check passed.
- `git add -A` after `git rm -r <dir>` can add files that only that dir's `.gitignore` ignored.
- A deploy restarts changed oneshots and waits for them: long ones need `restartIfChanged = false`.
  `lab-update apply` over SSH rolls back when the connection drops; `lab-apply` runs it as a unit.
- Units required by `docker-minecraft` restart Minecraft when they change; keep menus out of them.
- Minecraft RCON stalls on commands over ~1.4 kB; long commands go through the console pipe
  (`docker exec -u 1000 minecraft mc-send-to-console ...`), answers in `docker logs`.
- A shulker box `container` with counts above the item's stack size parses but is invalid: split stacks.
- slayer over SSH (`yassi@100.76.40.98`, key `~/.ssh/slayerKey`): put PowerShell into a script file and
  run it with `-File` (quoting breaks otherwise); zsh does not word-split `$VAR`. Tests run in
  `C:\Users\yassi\AppData\Local\Temp\slayer-test`. After editing an embedded script, regenerate the
  installer payloads (base64 of the LF file) or `test-install.ps1` fails on parity.
- `GetLastInputInfo` over SSH is meaningless (another session); the watcher runs in the desktop session.
- `gh`'s active account is `BanditStudent`; for 6FaNcY9 repos use `GH_TOKEN=$(gh auth token --user 6FaNcY9)`.
- The owner's local bandit-nix `main` carries an uncommitted `flake.lock`; fast-forwards that touch it
  need a stash.
- The auto-mode classifier refused some PC actions (e.g. creating `training.lock` on slayer): do not
  route around a refusal; give the owner the command.
